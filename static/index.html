    About the AI Model

    Project
    NeuroScan AI — AI-Based Alzheimer's MRI Classification System
    Input processing
    MRI image validation, grayscale conversion, resizing to 64 × 64 pixels, normalization and flattening into 4096 numerical features.
    Classification
    The model predicts one of two classes: Demented or Non-Demented, based on the project's binary label mapping.
    Reported test performance
    Accuracy: 67.53%
    Precision: 63.43%
    Recall: 82.78%
    F1-score: 71.83%
    Important limitation
    These are experimental dataset results. They do not establish clinical accuracy, and the model must not be used for diagnosis or treatment decisions.
